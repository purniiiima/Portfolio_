# Purnima Baroi — Portfolio

A modern, responsive portfolio showcasing my experience, projects, and technical skills as a **Full Stack Developer** with a primary focus on the **MERN Stack**.

## Tech Stack

* React.js
* Vite
* JavaScript
* Tailwind CSS
* Lucide React
* Motion
* HTML/CSS

## Features

* **Premium Responsive UI**: Sleek, accessible design optimized for mobile, tablet, and desktop screens with seamless dark/light mode.
* **Featured Project Showcase**: Interactive gallery with filtering across MERN Full Stack, Frontend, and Backend architectures with live links and GitHub repositories.
* **Professional Experience & Skills**: Comprehensive overview of work history, technical proficiencies (MongoDB, Express, React, Node.js, Next.js, TypeScript, Tailwind), and education (B.Tech CSE).
* **MERN-Focused Technical Profile**: Detailed architecture highlights and tech stack breakdown.
* **Resume View, Download & Print**: Dedicated interactive resume viewer with one-click print-to-PDF and copyable formatting.
* **Direct Connect**: Quick contact channels including email, GitHub (`purniiiima`), LinkedIn (`purnima-baroi`), and contact messaging.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.

## Production Build

```bash
npm run build
```
